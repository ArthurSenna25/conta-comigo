# Uso de dados nos serviços gratuitos da API Gemini

Nas condições para serviços gratuitos, o Google informa que pode usar entradas e respostas para desenvolver e melhorar produtos. Revisores humanos podem analisar esse conteúdo. O Google orienta a não enviar informações pessoais, confidenciais ou sensíveis a esses serviços.
